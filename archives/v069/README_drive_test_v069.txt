BlockSpin Drive Test v0.6.9 - TEST ISOLE DE CONDUITE

1. Arreter le script Auto Fish v0.6.8 : getgenv().BlockSpinV068.stop()
2. Executer blockspin_drive_test_v069.lua dans Xeno.
3. Placer la voiture au depart du pont (vers -351, 254, 844), monter au volant.
4. F11 : essayer le trajet PONT -> PARKING VENDEUR (19 points).
5. F12 : arreter immediatement le test de conduite.
6. Arret complet : getgenv().BlockSpinDriveTest069.stop()

ATTENTION : test non execute dans Roblox. Ne pas utiliser sans surveillance.
Aucune vente, aucun ATM, aucune ecriture de fichier, aucun trajet retour.
La commande W/A/S/D est envoyee au jeu meme sur clavier AZERTY; si la voiture
ne reagit pas, essayer dans Xeno :
getgenv().BlockSpinDriveTest069.keys={forward=Enum.KeyCode.Z,left=Enum.KeyCode.Q,back=Enum.KeyCode.S,right=Enum.KeyCode.D}
Puis relancer F11. Si la voiture se bloque, F12 puis signaler le point affiche.
